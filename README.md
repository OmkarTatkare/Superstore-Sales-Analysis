# Superstore-Sales-Analysis (Interactive Dashboard Creation using Power BI)

## Project Objective
The objective of this project was to analyze Superstore sales data and develop an interactive Power BI dashboard to monitor sales performance, profit trends, regional analysis, and product insights. The dashboard helps businesses make data-driven decisions by identifying high-performing categories, profitable regions, and customer segments.

## Dataset Used
- <a href="https://github.com/OmkarTatkare/Superstore-Sales-Analysis/blob/main/SuperStoreSalesData%20(1).csv.xlsx">Dataset</a>

## Tools & Technologies Used
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Questions (KPIs)
- What is the total sales, profit, and number of orders?
- Which states generate the highest sales and profit?
- Which customer segment contributes the most sales?
- Analyze annual sales and profit trends.
- Compare sales across different product categories and sub-categories.
- Which region performs best in terms of profit?
- What is the relationship between sales, profit, and quantity?
- Analyze profit margin (%) across states.
- Identify category-wise profit contribution.
- Visualize sales distribution by segment and product category.

## Process
- Collected and verified Superstore sales data.
- Performed data cleaning and preprocessing using Power Query.
- Removed inconsistencies, handled missing values, and formatted data types.
- Created calculated measures using DAX:
  - Total Sales
  - Total Profit
  - Profit Margin %
  - Total Orders
- Developed interactive visualizations including:
  - KPI Cards
  - Bar Charts
  - Donut Charts
  - Scatter Plots
  - Tree Maps
  - Maps
  - Slicers and Filters
- Designed a multi-page interactive Power BI dashboard for:
  - Sales Overview
  - Regional Analysis
  - Product Analysis
- Added interactive page navigation buttons to move between pages seamlessly.
- Implemented **CTRL + Click** functionality where users can press **CTRL** and directly select any of the following pages:
  - Sales Overview
  - Regional Analysis
  - Product Analysis
- Improved dashboard usability with dynamic interaction and smooth page transitions for better user experience.

## Project Insights
- Consumer segment generated the highest overall sales.
- California and New York were the top-performing states in terms of revenue and profit.
- Office Supplies contributed the largest share of category sales.
- Technology category generated strong profit margins.
- Sales showed significant growth from 2019 to 2020.
- Regional analysis highlighted the West region as one of the strongest contributors.
- Scatter plot analysis helped identify high-sales but low-profit products.
- Profit margin varied significantly across states and product categories.

## Final Conclusion
The Power BI dashboard provides a comprehensive business intelligence solution for monitoring sales and profitability performance. By leveraging interactive visualizations and real-time filtering, businesses can identify profitable regions, optimize product strategies, and improve decision-making processes. The project demonstrates how data visualization and analytics can transform raw business data into actionable insights.
